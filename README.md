# fitch-proofs

I have a mental illness and it's called fitchvizier.

All proofs are checked with [`check.sh`](/check.sh) in CI. See `.forgejo/workflows`.

## Structure

- `lpl`: Proofs from the [Language, Proof, and Logic](https://press.uchicago.edu/ucp/books/book/distributed/L/bo12734345.html) book
- `syllabus`: all fitch proofs listed in the [syllabus](https://fs.toostveen.nl/pub/UG/CS-1/logic/syllabus-2023-2024-Ma-AI.pdf) for year 2026-2027 (last changed 2023)
- `sample-exams`: proofs from exams 2022-2026, and midterms 2023-2026
  - These can be found on [StudCee](https://studysupport.svcover.nl)
- `hw`: HW1 and HW2 from year 2026-2027
- `misc`: random more-or-less interesting proofs, for example [left-distributivity for disjunction](/misc/left-distrib-or.fitch)
  - `quantifier-demorgan`: these are similar to the Add. Exercise 6 in the syllabus. Feel free to ignore to be honest.
  - `left-distrib-or`: this is similar to Add. Exercise 8 in the syllabus.

Obviously, the answers from the syllabus additional exercises are given, and one could easily claude this shit up. I didn't tho :D Pinky promise.
